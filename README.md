# 🌐 Welcome to the RAS Team Repo

Welcome to the RAS Team repository! This file serves as a guide for new members and a reference for all branches.

---

## 👥 Team Guidelines
1. Each member has their **own branch**:
   - Example: `shaima-fathy`, `ali-mohamed`
2. Do **not edit the `main` branch directly**
3. All tasks are listed on the **Board & Issues**
4. After completing any task:
   - Upload your files to your branch
   - Do not use pull request
   - Files should have the name & number of the task.
---

## 📝 How to Work on a Task
1. Open your branch on GitHub
2. Click **Add file → Upload files** to add your task files
3. Write a clear commit message,
    for example: 'completed'
---

## 📌 Updating the Board
- Move the related **Issue** on the Board according to the task status:
- **To Do → In Progress → Done**
- Regularly check the Board to see who is working on what.

---

## ⚠️ Important Notes
- Each branch is independent, so you can work without affecting the `main` branch.
